# Apple Explorer 2.0
Apple Explorer 2.0 is a web-based upgrade to Apple Explorer 1.0 that provides Agriculture and Agri-Food Canada with a user-friendly, searchable database of apple varieties to improve data management, information accuracy, and user experience.

## Setup and Installation
Ensure you have the following installed:
* Node.js
* MongoDB

Clone the repository
```bash
git clone <repo-url>
```

Open the repository and install the required dependencies
```bash
npm install
```

## Setting up the Backend
cd into the `AppleExplorer2.0\Backend` folder
```bash
cd Backend
```

Install the required dependencies
```bash
npm install
```

Copy the following .env files into the `Backend` folder
* .env
* .env2
